# Plan - Button

- 新增一個頁面 "按鈕"
- 按鈕頁是使用者登入後的第一個頁面
- 按鈕頁面裡有分頁
- 分頁裡可以添加按鈕

## 分頁

- 初始為 0 個分頁
  - 在 0 個分頁時，提示使用者現在沒有分頁和提示新增分頁的方式
- 使用者可以新增空白分頁
- 使用者可以刪除分頁
  - 沒有復原機制
  - 刪除前需要再確認
- 最少 0 個分頁
- 最多 50 個分頁
- 別人看不到自己的分頁
- 分頁不可轉移擁有者
- 可以自訂分頁的順序
- 分頁有編輯模式，進入編輯模式才可修改分頁內容
  - 編輯模式是以頁為單位，新增分頁、刪除分頁、自訂分頁順序不在編輯模式內
  - 可以自訂名稱
    - 上限 100 字
    - 可和其他分頁重複
  - Grid layout
  - 分頁只可以直向滾動
  - 允許內容直向超出畫面
  - 可以設定分頁裡的排版
    - 2 欄
    - 3 欄
    - 4 欄
    - 5 欄
  - 儲存：儲存整個分頁的變更並退出編輯模式
    - 多平台同時編輯時不進行衝突檢查，後儲存的內容會覆蓋先前儲存的內容。
  - 取消：捨棄整個分頁的變更並退出編輯模式
  - 使用者如果重整分頁或關閉分頁，視同取消
  - 使用者暫時不聚焦保持
  - 建議按下儲存前皆不寫入正式資料
- 儲存時，後端必須重新驗證所有按鈕資料
- 任何對已建立的分頁的操作都需要檢查分頁是否屬於目前登入使用者

## 按鈕

### 按鈕和設備

每個按鈕配對到一個指定設備的某個功能，
按下按鈕便會觸發設備的功能。

按鈕綁定目標為設備與功能，不綁定特定房間。
只要該設備存在於使用者可訪問的任一房間內，且設備與功能狀態允許操作，
按鈕即視為可用。

按鈕在下列情況會變為 disable，並且要讓使用者知道原因，依下列優先順序顯示：

1. 該設備不在使用者可訪問的任一房間內，可顯示「設備目前不可用」
2. 設備被後台禁用，可顯示「設備已被系統鎖定」
3. 設備被房主停用，可顯示「設備已被房主停用」
4. 該設備已離線，可顯示「設備已離線」
5. 功能無法使用，可顯示「功能無法使用」

上述情況解除時，按鈕自動恢復可用，例如：

- 設備恢復連線
- 設備重新啟用
- 後台解除禁用
- 使用者重新加入房間
- 設備重新加入使用者可訪問的任一房間
- ......等

### 顯示

依照排版自動改變大小

### 編輯模式

分頁在編輯模式時

- 可以在方格裡添加按鈕
  - 必須選擇對應的設備和功能
    - 只能顯示和選擇使用者目前有權限觸及的設備與可用功能
    - 可以和其他按鈕重複
  - 可以選擇按鈕的外型
    - 方形 (有導圓角)
    - 圓形
  - 可以選擇按鈕的顏色
    - 顏色可以自訂
  - 可以選擇按鈕的上面的圖示或是自訂文字
    - 圖示可參考數位電視遙控器
    - 文字可換行，上限 100 字
  - 可以選擇圖示(或是自訂文字)的顏色
    - 顏色可以自訂
- 每個按鈕占用一個方格
- 可以移動按鈕
  - 按鈕不能重疊
- 可以修改按鈕外觀，i.e. 不能修改設備關聯
- 可以刪除按鈕
  - 刪除按鈕不會改變其他按鈕的位置
- 每個分頁最多 100 個按鈕
- 如果修改了分頁的排版，保留按鈕的資料，只重製位置：
  - 按鈕會從第一格開始由左到右、由上到下依序填入，不保留空格。

儲存變更時，後端必須重新驗證所有按鈕資料，包括分頁擁有者、按鈕數量上限、位置不可重疊、設備與功能是否仍可被選擇、......等

 - 對於新增按鈕或修改設備關聯的操作，必須驗證設備與功能目前仍可被選擇。
 - 對於既有按鈕，若其綁定設備或功能目前不可用，允許保留該綁定，但按鈕在操作模式中維持 disable 狀態。

### 操作模式

編輯模式以外為操作模式。

使用者可以短按或長壓按鈕

- 短按：觸發設定好的設備功能
- 長壓：彈出按鈕資訊
  - 按鈕名稱或顯示文字
    - 文字大小依照使用者介面使用適中大小
    - 文字如果太長，顯示截斷
  - 綁定設備名稱
    - 如果是使用者無法的觸及設備，則不顯示內容
  - 綁定功能名稱
    - 如果是使用者無法的觸及設備，則不顯示內容
  - 所屬房間
    - 如果使用者不可訪問該房間，則不顯示內容
  - 目前狀態
    - 如果在 disable 狀態，顯示原因

使用者按下按鈕(短按)後要彈出等待畫面，阻止使用者進行其他操作，直到完成或超時：

- 前端送出按鈕操作時，應附帶一次性 request ID。後端需避免同一 request ID 重複建立工作。
  request ID 以同一使用者範圍內不可重複為原則，並需保存至工作完成後一段時間。
  若同一使用者以相同 request ID 重送相同操作，後端應回傳原本建立的工作 ID，不得重複建立工作。
- 後端應建立一筆工作，並回傳可追蹤狀態的 ID
  - 使用不可預測 ID
  - 需要記錄操作，建議欄位
    - 操作者
    - 按鈕
    - 設備
    - 功能
    - 狀態
    - 建立時間
    - 完成時間
    - 失敗原因
    - 來源
    - ......等
- 前端依 ID 查詢狀態，直到工作完成、失敗或超時後，才解除該使用者的操作鎖定
  - 使用者不可查詢其他使用者的工作狀態
- 若使用者已有未結束的工作，後端不得建立新的按鈕操作工作，應回傳既有工作 ID 或回傳操作處理中錯誤。
- 工作狀態
  - 等待中：操作已送出
  - 進行中：設備功能執行中
  - 成功：設備功能執行成功
  - 失敗：設備功能執行失敗
  - 設備離線：操作時設備不可用
  - 超時：時限內未取得結果
  - 無權限：操作時已失去權限
- 如果使用者關閉等待畫面，工作應在後端繼續執行。
- 如果使用者關閉頁面後再立刻開啟，如果關閉前的工作仍未結束(等待中、進行中)，則需要顯示該工作。
- 超時時間為 1 分鐘
- 超時只代表前端等待結束，不代表設備端工作一定取消。工作超時後，前端解除等待畫面與操作鎖定。若設備後續才回報結果，後端仍可更新操作紀錄，但不再主動影響前端等待畫面。

安全需求：前端 disable 狀態只作為顯示提示，不可作為安全依據。觸發按鈕時，後端必須重新檢查

- 分頁是否屬於目前登入使用者
- 按鈕是否屬於目前登入使用者
- 使用者是否仍有權限操作該設備與功能
- 設備是否仍存在
- 設備狀態：是否離線、房主停用、後台禁用
- 功能是否仍可用
