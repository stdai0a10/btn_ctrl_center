# Codex

## step 1

依照文件 `./.data/Story-Device.md` 裡的規格、建議，進行「房屋設備管理功能」的開發:

- 後端使用 Laravel 12
- 前端使用 Inertia + React
- 每完成 `Phase 分割建議` 裡的一個階段就進行一次提交

## step2

更新前端網頁結構

- 使用者登入前的首頁顯示以下連結
  - 帳號管理
  - 設備管理
  - 登入/註冊
- 使用者登入後的首頁顯示以下連結
  - 帳號管理
  - 設備管理
  - 登出
- 如果使用者在未登入的情況下開啟「帳號管理」或是「房屋管理」，導引使用者到登入頁面
- 使用者登入後自動回到登入前的頁面，沒有指定的話就回到首頁
- cookie 或 token 過期的情況下，導引使用者到登入頁面，登入後再回到登入前的頁面
